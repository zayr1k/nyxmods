## Что это

Nyx Mods — игровая платформа для Windows: находит игры и лаунчеры, которые у тебя уже есть, управляет модами и сборками и объединяет тебя с друзьями. Твои лаунчеры она не заменяет — нажал «Играть», и открылся нужный с нужной версией.

**Первая поддерживаемая игра — Minecraft: Java Edition** (официальный лаунчер, Legacy Launcher, TLauncher, Prism и другие). **Скоро — другие игры**: Nyx устроен так, что новые игры подключаются к тем же модам, сборкам, ленте и комьюнити.

## Возможности

### 🎮 Игры и моды
> Сейчас — для Minecraft; с каждой новой игрой те же инструменты появятся и для неё.

- **Автопоиск лаунчеров** и всех установленных версий — без входа в аккаунты и без чтения паролей.
- **Моды в один клик**: включить, выключить, добавить перетаскиванием, удалить в корзину. Nyx предупредит, если мод не под твой загрузчик (Forge / Fabric / NeoForge / Quilt).
- **Каталог Modrinth** под твою версию: установка вместе с зависимостями, каждый файл проверяется по хешу.
- **Скачивание версий Minecraft** с серверов Mojang — Java ставится вместе с игрой.

### 📦 Сборки
- Готовые сборки с Modrinth, импорт `.mrpack`, «Сохранить мои моды».
- **Включил сборку — твои моды аккуратно убраны в сторону, выключил — вернулись.** Ничего не теряется.

### 👥 Комьюнити
- **Друзья по нику** и **личные сообщения** в реальном времени.
- **Кидай моды и сборки прямо в чат** — друг ставит их одной кнопкой.
- **Лента сборок**: публикуй свои, лайкай, ставь чужие в один клик.
- **Форум** с разделами и ответами ветками — как на любимых игровых форумах.
- Аватарка и «О себе».

### ⚙️ Удобство
- Работает в **трее** — закрыл окно, загрузки продолжаются.
- **Запуск вместе с Windows** (можно выключить).
- **Автообновление** при запуске, как в Discord.
- Тёмный минималистичный интерфейс, русский и английский язык.

## Установка

1. Скачай [**Nyx-Mods-Setup.exe**](https://github.com/zayr1k/nyxmods/releases/latest) из последнего релиза.
2. Запусти — установка в один клик, права администратора не нужны.
3. Если Windows покажет **«Windows защитила ваш компьютер»** — нажми **«Подробнее» → «Выполнить в любом случае»**. Так бывает с новыми программами без платной цифровой подписи.

Дальше Nyx обновляется сам.

## Безопасность

- **Никаких чужих файлов.** В ленту и чат можно отправить только ссылки на моды с Modrinth — сами файлы скачиваются с Modrinth и проверяются по хешу. Вирус через Nyx не передать.
- **Аватарки** — только картинки: Nyx перерисовывает их в 256×256 на твоём компьютере, твой файл никуда не загружается.
- **На форуме ссылки удаляются автоматически** — прямо на сервере.
- Nyx **не читает пароли и токены** твоих лаунчеров и не обходит лицензии — играешь через свой лаунчер, как обычно.
- Писать в личку могут **только друзья**, есть жалобы и защита от спама.
- Приложение изолировано (sandbox, строгий CSP, проверка целостности), обновления скачиваются только с GitHub и сверяются по SHA-512.

## Частые вопросы

<details>
<summary><b>Нужен ли аккаунт?</b></summary>

Для модов, сборок и игры — нет. Аккаунт Nyx (почта + пароль + ник) нужен только для друзей, чата, ленты и форума. Он не связан с Minecraft или Microsoft.
</details>

<details>
<summary><b>Где мои моды, если я включил сборку?</b></summary>

Они в безопасности: Nyx отложил их в сторону и вернёт, как только ты выключишь сборку.
</details>

<details>
<summary><b>Как полностью закрыть Nyx?</b></summary>

Правый клик по значку у часов → «Выйти из Nyx». Или выключи «Сворачивать в трей при закрытии» в настройках.
</details>

<details>
<summary><b>Какие игры поддерживаются?</b></summary>

Первая — Minecraft: Java Edition. Nyx — платформа для многих игр, новые появятся в следующих обновлениях. Напиши, какие хочешь, в **Форум → Общее**.
</details>
